# 灵动岛窗口原型（A 阶段）

原生 AppKit / SwiftUI 顶部窗口已接入 XStats 当前实例的真实系统指标、AI 用量及休息计时。窗口不持久化开关和场景，重新启动后需要再次打开。

在 **设置 → 功能 → 可选功能 → 灵动岛** 点击“打开”。窗口运行期间菜单栏出现独立的胶囊图标，可以展开、收起、切换显示器或关闭灵动岛。

也可以退出 XStats 后，使用正常主程序启动并同时打开灵动岛：

```sh
open /Applications/XStats.app --args --island
```

- 系统场景收起时显示真实 CPU 占用；展开后显示已用内存、CPU 温度与整机功耗。复用 `MetricsStore` 与 `MetricsHub`，按当前展示内容合并采样需求，不创建独立采集器。展开时使用现有每秒实时采样，收起后移除内存、温度及功耗的额外需求。
- 遵守基础监控和能耗开关，不为展示自动开启功能。未启用时显示“尚未启用”，等待首个采样或硬件不支持时显示“—”，不会填入模拟数值。
- AI 场景复用当前配置的 `AIUsageController`、原有账号、Magpie 或本机来源及原有刷新周期。显示今日 Token 和各账号的订阅额度，不合并不同账号的额度。已有缓存或读取失败保留的旧值带有读取时间和旧数据提示；打开窗口与切换场景不新增扫描或网络轮询。
- 休息场景复用 `RestController` 的当前阶段、剩余时间与开始／暂停／继续操作，与主窗口和迷你 HUD 同步。仅当前场景可见时加入原有倒计时显示需求；没有独立计时器。
- 点击收起的岛立即展开，悬停约 250 ms 显示简略预览；离开简略预览时收起。明确展开后移开指针仍保持展开，点击外部或按 Esc 收起。悬停不抢键盘焦点、不监听其他应用的键盘。
- 刘海屏幕读取系统安全区域与摄像头空隙，内容留在刘海下方；无刘海屏幕显示位于菜单栏下方的胶囊。默认选择内建屏幕，无内建屏幕时使用主屏幕。
- 屏幕配置变化后重新定位；锁屏、显示器休眠、系统休眠时释放窗口内容及其展示需求，恢复后从收起状态开始。关闭时移除观察者与输入监听，其他窗口和历史记录所需的原有采集继续按其需求运行。
- 窗口形状使用短过渡，同步裁剪内容；系统开启“减少动态效果”时即时变化，没有循环装饰动画。

本阶段使用原创实现，不包含 vorssaint-utils 的源代码或素材。真实多显示器、刘海屏、全屏应用与 Mission Control 的组合仍需在对应硬件上验证。
