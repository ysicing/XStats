# 灵动岛窗口与设置

原生 AppKit / SwiftUI 顶部窗口接入 XStats 当前实例的真实系统指标、AI 用量及休息计时。默认关闭；启用状态、场景和展示偏好随应用重启保留。

在 **设置 → 功能 → 可选功能 → 灵动岛** 启用，之后可以打开“设置”。显示内容可独立勾选系统、AI 用量与休息场景，以及 CPU、内存、温度与功耗指标；至少保留一个场景和一项系统指标，仅有一个场景时隐藏切换栏。取消当前场景后自动切换到首个保留场景，默认场景仅可从保留的场景中选择。显示选项包含目标屏幕、默认场景、显示样式、展开尺寸、菜单栏间距和全屏隐藏；交互选项包含点击展开、悬停预览、悬停展开及对应延迟。窗口运行期间菜单栏出现独立的胶囊图标，可以展开、收起、切换显示器或关闭灵动岛。

也可以退出 XStats 后，使用正常主程序启动并启用灵动岛：

```sh
open /Applications/XStats.app --args --island
```

- 系统场景收起时显示首个已选指标，按 CPU、内存、温度、功耗的顺序确定；展开后显示其余已选指标。默认全部选中，与原有显示一致。复用 `MetricsStore` 与 `MetricsHub`，按当前展示内容合并采样需求，不创建独立采集器。展开时使用现有每秒实时采样，收起后只保留首个已选指标的展示需求，取消勾选立即移除对应的额外采样需求；其他窗口和历史所需的采样不受影响。
- 遵守基础监控和能耗开关，不为展示自动开启功能。未启用时显示“尚未启用”，等待首个采样或硬件不支持时显示“—”，不会填入模拟数值。
- AI 场景复用当前配置的 `AIUsageController`、原有账号、Magpie 或本机来源及原有刷新周期。显示今日 Token 和各账号的订阅额度，不合并不同账号的额度。已有缓存或读取失败保留的旧值带有读取时间和旧数据提示；打开窗口与切换场景不新增扫描或网络轮询。
- 休息场景复用 `RestController` 的当前阶段、剩余时间与开始／暂停／继续操作，与主窗口和迷你 HUD 同步。仅当前场景可见时加入原有倒计时显示需求；没有独立计时器。
- 点击收起的岛立即展开，默认悬停 250 ms 显示简略预览；离开简略预览时收起。悬停展开可设置等待时间和移开后的收起延迟，重新移入会取消待执行的收起。明确点击展开后移开指针仍保持展开，点击外部或按 Esc 收起。悬停不抢键盘焦点、不监听其他应用的键盘。
- 收起态高度为 32 点，宽度按当前读数在 120–260 点之间调整，仅保留场景图标、读数与展开提示。展开可选紧凑（360 × 300 点）、标准（420 × 320 点）或自定义（宽 360–600 点、高 300–480 点），并按可用屏幕空间约束。默认使用“悬浮胶囊”，所有状态均位于菜单栏下方，间距可选 8–32 点；菜单栏自动隐藏时仍预留系统菜单栏高度。选择“顶部贴合”后，外形连接屏幕顶边，使用内凹肩部和圆角底边，展开方向保持向下；读数与按钮仍在菜单栏及刘海下方，顶部连接区域不放内容。贴合模式隐藏间距设置，保留原有间距供切回悬浮时使用；收起宽度额外计入肩部及摄像头宽度，展开尺寸包含两侧肩部，连接区高度另计。刘海屏幕以摄像头空隙居中。两种模式均低于系统菜单与状态栏层级，菜单栏可覆盖顶部连接区域；不申请辅助功能权限、不检测菜单位置、不增加轮询。
- 默认选择内建屏幕，无内建屏幕时使用主屏幕。手动选择的显示器以稳定 UUID 保存在本机，断开时临时回退，重新连接后恢复选择。设置备份保存展示偏好，恢复时保留本机的显示器选择。
- 默认全屏时隐藏。桌面、前台应用或屏幕变化时，通过公开窗口边界判断所选屏幕是否被前台应用完全覆盖，不读取窗口标题、不申请辅助功能权限，也不增加定时轮询；无边框覆盖整屏的窗口也按全屏处理。此识别仍需覆盖不同应用与多显示器组合。
- 屏幕配置变化后重新定位；桌面与前台应用切换经事件防抖后也校正位置，即使全屏判断未变化仍将可见窗口重新锚定顶边，不增加轮询；全屏隐藏、锁屏、显示器休眠、系统休眠时释放窗口内容及其展示需求，恢复后从收起状态开始。关闭时移除观察者与输入监听，其他窗口和历史记录所需的原有采集继续按其需求运行。
- 窗口形状沿用设计令牌的 180 ms 短过渡，同步裁剪内容，中途可反向操作；键盘操作与系统开启“减少动态效果”时即时变化，读数不做装饰动画。

贴合模式的连接区按实际菜单栏占用和刘海安全区留白：无刘海且菜单栏自动隐藏时，收起总高度为 32 点，不另加菜单栏高度；临时呼出系统菜单时，系统界面优先覆盖岛。悬浮模式始终预留菜单栏高度，保持与系统菜单的间距。

本阶段使用原创实现，不包含 vorssaint-utils 的源代码或素材。真实多显示器、刘海屏、全屏应用与 Mission Control 的组合仍需在对应硬件上验证。

列表沿用 `MainActorForEach` 隔离模型读取，避免 macOS 15 的后台 DisplayLink 调用构建闭包时触发主线程断言。在图形会话中运行：

```sh
swift test --package-path Packages/XStatsKit --no-parallel \
  --filter 'IslandListIsolationTests|IslandGeometryTests|IslandInteractionTests|IslandWindowLifecycleTests'
```

用例覆盖实际列表回调的后台构建（含嵌套额度周期）、长译文及左右书写布局、偏好持久化、缺少样式字段的旧偏好与旧备份兼容、贴合与悬浮切换时的旧动画取消、延迟交互取消、窗口几何约束，以及关闭／全屏隐藏／锁屏／休眠时的展示需求释放。后台回调测试可在开发机复现隔离边界，但不能代替 macOS 15 的真实 DisplayLink 验收。
