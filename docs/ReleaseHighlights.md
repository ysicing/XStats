# XStats 新版亮点

客户端从 [随包亮点清单](../Packages/XStatsKit/Sources/XStatsUI/Resources/ReleaseHighlights.json) 读取各版本条目。单版标题包含版本号。跨版按最近五个正式版本筛选，最多展示五项，每项标注所介绍的版本。同一功能以最新改动为准。

每项亮点的功能名和说明随版本提供中英文两份。简体、繁体中文界面均显示中文原文，其他界面语言显示英文。弹窗标题和按钮沿用应用界面语言。

每次主程序发版前确定本版亮点。正式版本必须在清单中登记一次，无亮点时填写 `features: []`。发版脚本在写入 `project.yml` 的版本号与构建号前检查目标版本。每一项可单独指定单版图标 `singleVersionSymbol`，或用 `showsActivityChart` 在单版页面展示活动示例图。

全新安装以当前版本为已读起点。首次迁移时，客户端通过 1.4.6 引入的本机偏好识别已有安装，并以 1.6.7 为基线。直接从 1.4.6 之前升级且缺少该偏好的用户按全新安装处理。后续升级以本机已读版本为准，正常打开主窗口时按需展示，完成后记录当前版本。完整变更见 [更新日志](../CHANGELOG.md)。
