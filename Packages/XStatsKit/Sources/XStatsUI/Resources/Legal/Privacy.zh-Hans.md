# XStats 隐私政策

生效日期：2026 年 10 月 6 日

本政策说明 XStats 使用的数据、联网服务和授权要求。联系邮箱：i@xiai.me。

## 1. 本机数据与授权

- **系统监控**：监控指标与进程列表在本机处理，历史记录和偏好设置保存在本机。
- **日历**：系统日程与到期提醒默认关闭。授权后，在面板打开时读取所选列表中当前月历范围的内容；关闭面板后清空展示列表。列表选择保存在本机，可在日历设置中关闭读取或在系统设置中撤销权限。
- **AI 用量**：默认关闭，需要安装并运行 Magpie。开启后通过本地接口读取账号额度、Token 与费用，关闭后停止读取。Apple 智能进程解释在本机运行。
- **诊断导出**：由你选择保存位置，内容可能包含设置摘要、最近三天的系统日志、清理记录与崩溃报告；分享前请检查内容。
- **音频**：默认关闭。系统音量和设备切换在本机完成；macOS 14.4 及以上的应用音量调节需要系统音频捕获授权。声音在本机实时处理，应用音量和输出设备偏好保存在本机。关闭界面后调节继续生效，关闭功能或休眠时停止处理；可在系统设置中撤销授权。
- **网络监视器**：macOS 15 及以上可用，默认关闭，需要批准系统扩展。在页面可见时记录新连接的应用、目标地址、端口、协议、时间和结束状态，最多 512 条，保存在内存中。暂停、隐藏页面、锁屏或休眠时停止观察，关闭功能后清空记录并关闭过滤配置。国家地图从 `c.ysicing.net` 下载公共 IP 国家数据库，缓存到本机用于离线查询；地图表示国家级归属。

## 2. 更新检查与安装统计

检查更新时，应用向 XStats 更新服务发送版本号和安装标识的 SHA-256 哈希。安装标识在本机由随机值或机器序列号生成。更新服务入口为 `apps.china.12306.work`、`apps.12306.work` 和 `apps-api.xiai.me`。

服务保存哈希、版本、首次及最近检查时间和累计次数，用于安装量、版本分布与活跃情况统计；这些汇总记录长期保存，可申请删除。请求 IP 在内存中用于一分钟限流，网络基础设施可能按自身规则处理连接元数据。

可在“设置 → 关于”选择检查频率，或选择“从不”后仅手动检查。新版本由你决定是否下载安装。查询或删除统计记录时，可通过邮箱联系我们，并提供安装标识哈希以便定位。

## 3. 联网功能

- **公网 IP 与归属地**：公网 IP 查询使用 Cloudflare `1.1.1.1`，失败时回退到 ipify；归属地、ASN、网络类型与纯净度查询向 `cleanip.io` 发送公网 IP，结果缓存在本机。
- **WebRTC 检测**：向 `ipwho.is` 发送检出的 HTTP 和 STUN 公网 IP，查询地区、城市、机构、ISP 与服务商域名。结果在本机缓存 7 天，最多 256 个 IP；过期后按需刷新，失败时保留旧结果。关闭窗口或系统暂停时取消查询。
- **网络诊断**：连接探测、测速、出口检测与 DNS 查询会连接所选目标、测试节点、网站或 DNS 服务；对方可获取连接元数据及测试所需内容。
- **全球探针**：向 Globalping 提交输入的目标域名；测量参数和结果可通过测量 ID 被他人查询，请仅提交适合公开的目标。

第三方服务按各自的隐私政策处理请求信息。

## 4. 数据管理与联系

本机数据由你和 macOS 管理。卸载后，偏好、日志和已导出的诊断包可能保留，可自行删除。关闭相应功能可停止后续查询。

如需了解、更正或删除可定位的服务端记录，或有隐私问题，请联系 i@xiai.me。邮件用于处理你的请求，并按该用途及适用义务所需的期限保存。

处理方式发生重大变化时，我们会更新本政策及生效日期，并在应用或项目页面提供新版本。
