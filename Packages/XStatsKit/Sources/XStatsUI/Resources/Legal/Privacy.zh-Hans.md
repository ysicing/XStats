# XStats 隐私政策

生效日期：2026 年 10 月 6 日

本政策说明 XStats 在 macOS 上处理哪些信息，以及哪些功能会连接外部服务。XStats 自有服务仅保存第 2 节所述的更新统计汇总；应用自身的其他持久化数据保存在本机，不上传到 XStats 自有服务器。联网测试会向相应第三方发送完成测试所需的请求，详见第 3 节。联系邮箱：i@xiai.me。

## 1. 本机处理的数据

CPU、GPU、内存、网络、温度、风扇、进程等监控数据来自本机系统接口，其指标、历史记录和进程列表仅在本机处理，不上传到 XStats 更新服务。设置保存在本机应用偏好中。

日历中的系统日程与到期提醒默认关闭。你主动授权后，XStats 通过 macOS 日历接口在面板打开时读取所选列表的当前月历范围，仅在本机展示，不创建、修改或删除记录，不上传内容，也不将其写入设置备份或小组件摘要。关闭面板后清空展示列表；列表选择保存在本机，可在日历设置中关闭读取，也可在系统设置中撤销权限。

“AI 用量”默认关闭；开启后读取本机 Codex / Claude Code 会话日志，按模型汇总 Token 用量，并查询相应的订阅额度。Codex 优先通过本机已安装的 Codex CLI App Server 读取额度，由 CLI 自行维护登录；若该方式不可用，则使用本机 CLI 登录凭据直连额度接口。应用也会读取本机 ID token 中的套餐有效期，仅在账号匹配时展示。Claude Code 使用本机 CLI 凭据直连。查询请求会向对应服务发送登录令牌；令牌不写入 XStats 设置或统计数据库，日志内容不会随额度请求发送。接口可能变化或限流，额度查询失败不影响本机 Token 统计。关闭此功能后停止后续扫描和额度查询。Apple 智能进程解释在本机运行，不把进程信息发送给其他 AI 服务。
如果你为 Codex 或 Claude Code 手动配置 Sub2API 额度备选来源，只有对应来源的自动额度查询失败时，应用才会连接你为它填写的 HTTPS 服务器。两份配置分别保存，并核对查询账号的平台。管理员邮箱与密码在登录时发送到对应服务器；密码分别保存在本机钥匙串，地址、邮箱和账号 ID 只保存在本机设置中。后台额度请求使用 `force=false`，不触发主动探测。移除某个来源的配置会删除其本机保存的 Sub2API 密码和连接信息。

诊断信息由你主动导出到指定位置，不会自动上传。导出的压缩包可能包含应用设置摘要、最近三天的系统日志、清理记录和崩溃报告；分享前请自行检查内容。

“音频”默认关闭。系统音量、静音与输出/输入设备切换通过本机 Core Audio 接口完成；设备不支持的控制不会启用。macOS 14.4 及以上可在你明确授权系统音频捕获后调节应用音量。声音只在本机实时处理，不录制、保存或上传。应用音量及独立输出设备偏好按应用标识保存在本机；关闭界面后已设置的音量继续生效，关闭功能或休眠时停止处理并释放音频对象。可在系统设置中撤销授权。

“网络监视器”仅在 macOS 15 及以上开放，默认关闭。主动启用并批准系统扩展后，仅在查看页面可见时记录新连接的应用、目标地址、端口、协议与时间及结束状态，全部连接放行，不读取通信内容。最多保留 512 条界面记录，仅存于内存，不写入历史数据库、设置备份或小组件，不上传。国家级地图首次使用及更新时从 `c.ysicing.net` 下载公共 IP 国家数据库并缓存到本机，随后离线查询；下载请求不附带安装标识、目标 IP 或连接记录，不代表设备精确位置。暂停保留当前画面并停止读取；页面隐藏、锁屏或休眠时停止观察，关闭模块清空界面记录并关闭过滤配置。

## 2. 更新检查与安装统计

启用自动检查更新时，应用按你在“设置 → 关于”选择的策略（运行时静默、启动时、每日、每周或每月）向 XStats 更新服务发送当前版本和安装标识的 SHA-256 哈希，并获取版本清单；选择“从不”时仅在你手动检查后发送。“运行时静默”仍会检查，但不会弹出新版本提示。中国地区依次尝试 `apps.china.12306.work`、`apps.12306.work`、`apps-api.xiai.me`；其他地区依次尝试 `apps.12306.work`、`apps-api.xiai.me`、`apps.china.12306.work`。只有前一入口失败时才串行尝试下一入口，成功后停止，全部失败后结束本轮。安装标识在本机由随机值或机器序列号生成，序列号原文不发送。

更新服务的业务数据库保存哈希、当前版本、首次及最近检查时间、累计检查次数，用于去重统计安装量、版本分布和活跃情况。此汇总记录不设自动到期清理；更新服务不建立逐次请求明细，应用服务不将请求 IP 写入业务数据库。请求 IP 会在内存中用于一分钟限流。网络基础设施可能按其自身规则处理连接元数据。

你可以在“设置 → 关于”将自动检查更新设为“从不”；发现新版本后，由你决定是否下载安装。若希望查询或删除关联的服务端汇总记录，请通过下方邮箱联系我们；为了定位记录，可能需要你提供本机安装标识的哈希。

## 3. 其他联网功能

- 启用“AI 用量”后，Codex 优先通过本机已安装的 Codex CLI App Server 查询额度；不可用时使用本机 Codex 登录凭据直连 `chatgpt.com`。Claude Code 使用本机登录凭据直连 `api.anthropic.com`。相应服务可以看到登录令牌及连接元数据。每个来源最近一次成功的额度快照保存在本机 `ai-usage.sqlite`，包含百分比、重置时间、套餐类型与有效期、可用重置次数及其最早到期时间、数据来源及获取时间，不含登录令牌、账号标识或重置券 ID；查询失败时可显示并标记为旧数据。认证失效或移除手动配置会删除对应快照。关闭功能后停止查询并隐藏额度，本地快照仍保留以便重新启用；额度结果不上传到 XStats 服务器。
- 启用本地 AI 用量且用量界面可见时，费用估算按需读取 `models.dev/api.json` 的公开模型基础单价；选择人民币时另读取 `open.er-api.com/v6/latest/USD` 的参考汇率。请求不发送会话日志、Token 数量、模型使用记录或登录凭据，第三方可看到连接元数据。单价与汇率分别在本机缓存 24 小时和 12 小时后按需更新，失败时可继续显示带更新时间的旧缓存。关闭界面、关闭功能或系统暂停时取消不再需要的请求。费用根据本机 Token 统计计算，不含阶梯加价，不代表订阅账单。
- Codex CLI 可直接返回重置次数及到期明细。直连额度接口作为后备方式时，仅在存在可用次数时，另向 `chatgpt.com/backend-api/wham/rate-limit-reset-credits` 发起只读查询；查询失败仍保留已有额度与次数，不执行或自动消耗重置。
- 配置 Codex 或 Claude Code 的 Sub2API 备选来源后，对应的自动额度查询失败时，应用直接请求你为该来源指定的 Sub2API 服务器；该服务器会收到管理员邮箱、密码、登录令牌和查询账号 ID。XStats 不预设 Sub2API 服务器，也不向 XStats 服务器上传这些信息或额度结果。
- 打开网络详情且启用公网 IP 查询时，应用直接访问 Cloudflare `1.1.1.1`，失败时回退到 ipify；归属地、ASN、网络类型和纯净度查询会把公网 IP 发送给 `cleanip.io`。结果在本机缓存。
- 启用连接探测时，应用向所选目标发送 ICMP 探测。测速、出口检测和 DNS 查询仅在你使用相应功能时，直接连接所选测试节点、网站或 DNS 服务；对方可看到连接元数据及测试所需内容。
- 使用全球探针时，应用会把你输入的目标域名提交给 Globalping。测量参数和结果可通过测量 ID 被他人查询，请勿输入不希望公开的目标。

上述第三方服务不由 XStats 控制，其对请求信息的处理以各自政策为准。除更新服务外，这些请求不经 XStats 服务器转发。

## 4. 保存、控制与联系我们

本机数据由你和 macOS 管理；卸载应用不一定自动删除本机偏好、日志或你已导出的诊断包。可通过关闭相应功能停止后续查询，并自行删除本机相关数据。

更新服务的哈希汇总记录按第 2 节说明保留，不自动过期。通过邮件联系我们时，我们仅将邮件用于处理你的请求，并按处理请求及适用义务所需的期限保存。你可通过 i@xiai.me 请求了解、更正或删除我们可定位的关联记录，或提出隐私问题。

如处理方式发生重大变化，我们会更新本政策及生效日期，并在应用或项目页面提供新版本。
