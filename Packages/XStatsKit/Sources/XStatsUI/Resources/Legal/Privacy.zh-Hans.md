# XStats 隐私政策

生效日期：2026 年 9 月 23 日

本政策说明 XStats 在 macOS 上处理哪些信息，以及哪些功能会连接外部服务。XStats 自有服务仅保存第 2 节所述的更新统计汇总；应用自身的其他持久化数据保存在本机，不上传到 XStats 自有服务器。只有你自行配置并主动使用 WebDAV 同步时，设置备份才会保存在你配置的服务器；联网测试也会向相应第三方发送完成测试所需的请求，详见第 3、4 节。联系邮箱：i@xiai.me。

## 1. 本机处理的数据

CPU、GPU、内存、网络、温度、风扇、进程等监控数据来自本机系统接口，其指标、历史记录、硬件序列号和进程列表仅在本机处理，不上传到 XStats 更新服务。设置保存在本机应用偏好中；仅在你主动使用 WebDAV 同步时，所选设置会形成远端备份。

“AI 用量与额度”默认关闭；开启后读取本机 Codex / Claude Code 会话日志，按模型汇总 Token 用量，并自动只读检查对应 CLI 的登录凭据，直接向 Codex、Claude 的额度接口查询 5 小时及每周用量。查询请求会向对应服务发送登录令牌；令牌不写入 XStats 设置或统计数据库，日志内容不会随额度请求发送。接口可能变化或限流，额度查询失败不影响本机 Token 统计。关闭此功能后停止后续扫描和额度查询。Apple 智能进程解释在本机运行，不把进程信息发送给其他 AI 服务。
如果你为 Codex 或 Claude Code 手动配置 Sub2API 额度备选来源，只有对应来源的自动额度查询失败时，应用才会连接你为它填写的 HTTPS 服务器。两份配置分别保存，并核对查询账号的平台。管理员邮箱与密码在登录时发送到对应服务器；密码分别保存在本机钥匙串，地址、邮箱和账号 ID 只保存在本机设置中，不进入 WebDAV 备份。后台额度请求使用 `force=false`，不触发主动探测。移除某个来源的配置会删除其本机保存的 Sub2API 密码和连接信息。

诊断信息由你主动导出到指定位置，不会自动上传。导出的压缩包可能包含应用设置摘要、最近三天的系统日志、清理记录和崩溃报告；分享前请自行检查内容。

## 2. 更新检查与安装统计

启用自动检查更新时，应用按你在“设置 → 关于”选择的策略（运行时静默、启动时、每日、每周或每月）向 XStats 更新服务发送当前版本和随机安装标识的 SHA-256 哈希，并获取版本清单；选择“从不”时仅在你手动检查后发送。“运行时静默”仍会检查，但不会弹出新版本提示。中国地区优先连接 `x-stats.china.12306.work`，其他地区优先连接 `xstats-apps.12306.work`，首选失败时才尝试另一端。原始随机值仅保存在本机偏好设置中，不在 WebDAV 备份中。

更新服务的业务数据库保存哈希、当前版本、首次及最近检查时间、累计检查次数，用于去重统计安装量、版本分布和活跃情况。此汇总记录不设自动到期清理；更新服务不建立逐次请求明细，应用服务不将请求 IP 写入业务数据库。请求 IP 会在内存中用于一分钟限流。网络基础设施可能按其自身规则处理连接元数据。

你可以在“设置 → 关于”将自动检查更新设为“从不”；发现新版本后，由你决定是否下载安装。若希望查询或删除关联的服务端汇总记录，请通过下方邮箱联系我们；为了定位记录，可能需要你提供本机安装标识的哈希。

## 3. 其他联网功能

- 启用“AI 用量与额度”后，应用使用本机 Codex / Claude Code 的登录凭据，分别直接请求 `chatgpt.com` 和 `api.anthropic.com` 的额度接口；对方可以看到登录令牌及连接元数据。每个来源最近一次成功的额度快照保存在本机 `ai-usage.sqlite`，包含百分比、重置时间、数据来源及获取时间，不含登录令牌；查询失败时可显示并标记为旧数据。认证失效或移除手动配置会删除对应快照。关闭功能后停止查询并隐藏额度，本地快照仍保留以便重新启用；额度结果不上传到 XStats 服务器。
- 配置 Codex 或 Claude Code 的 Sub2API 备选来源后，对应的自动额度查询失败时，应用直接请求你为该来源指定的 Sub2API 服务器；该服务器会收到管理员邮箱、密码、登录令牌和查询账号 ID。XStats 不预设 Sub2API 服务器，也不向 XStats 服务器上传这些信息或额度结果。
- 打开网络详情且启用公网 IP 查询时，应用直接访问 Cloudflare `1.1.1.1`，失败时回退到 ipify；归属地、ASN、网络类型和纯净度查询会把公网 IP 发送给 `cleanip.io`。结果在本机缓存。
- 启用连接探测时，应用向所选目标发送 ICMP 探测。测速、出口检测和 DNS 查询仅在你使用相应功能时，直接连接所选测试节点、网站或 DNS 服务；对方可看到连接元数据及测试所需内容。
- 使用全球探针时，应用会把你输入的目标域名提交给 Globalping。测量参数和结果可通过测量 ID 被他人查询，请勿输入不希望公开的目标。

上述第三方服务不由 XStats 控制，其对请求信息的处理以各自政策为准。除更新服务外，这些请求不经 XStats 服务器转发。

## 4. WebDAV 设置同步

WebDAV 服务器地址、用户名和密码均由你自行填写并保存；XStats 不提供或预设 WebDAV 同步服务器。只有你主动上传或下载时，应用才会通过 HTTPS 与该服务器通信。上传的 JSON 文件包含偏好设置，不包含监控数据、历史记录、原始安装标识或 WebDAV 连接信息。WebDAV 密码保存在本机钥匙串；备份文件在服务器上不由 XStats 额外加密。远端文件的保存与删除由你及所选服务商管理。

## 5. 保存、控制与联系我们

本机数据由你和 macOS 管理；卸载应用不一定自动删除本机偏好、日志或你已导出的诊断包。可通过关闭相应功能停止后续查询，并在本机或 WebDAV 服务端删除相关数据。

更新服务的哈希汇总记录按第 2 节说明保留，不自动过期。通过邮件联系我们时，我们仅将邮件用于处理你的请求，并按处理请求及适用义务所需的期限保存。你可通过 i@xiai.me 请求了解、更正或删除我们可定位的关联记录，或提出隐私问题。

如处理方式发生重大变化，我们会更新本政策及生效日期，并在应用或项目页面提供新版本。
