# XStats 隐私政策

生效日期：2026 年 11 月 26 日

本政策说明 XStats 使用的数据、联网服务和授权要求。联系邮箱：i@xiai.me。

## 1. 本机数据与授权

- **系统监控**：监控指标与进程列表在本机处理，历史记录和偏好设置保存在本机。
- **日历**：系统日程与到期提醒默认关闭。授权后，在面板打开时读取所选列表中当前月历范围的内容；关闭面板后清空展示列表。列表选择保存在本机，可在日历设置中关闭读取或在系统设置中撤销权限。
- **AI 用量**：默认关闭。开启后从本机或你配置的远端 Magpie 读取账号额度、Token 与费用，关闭后停止读取。远端的网关密钥保存在本机钥匙串，并随请求发送到配置的网关。使用 HTTP 时，请求和响应在传输中不加密。Apple 智能进程解释在本机运行。
- **诊断导出**：由你选择保存位置，内容可能包含设置摘要、最近三天的系统日志、清理记录与崩溃报告；分享前请检查内容。
- **音频**：默认关闭。系统音量和设备切换在本机完成；macOS 14.4 及以上的应用音量调节需要系统音频捕获授权。声音在本机实时处理，应用音量和输出设备偏好保存在本机。关闭界面后调节继续生效，关闭功能或休眠时停止处理；可在系统设置中撤销授权。
- **网络监视器**：macOS 15 及以上可用，默认关闭，需要批准系统扩展。在页面可见时记录新连接的应用、目标地址、端口、协议、时间、结束状态与系统字节统计，连接与流量历史写入本机 SQLite 数据库，在采集或查看时按最近15分钟时间窗清理；停用或退出后不运行后台清理，过期数据在下次访问时删除；界面只加载当前页和图表所需的少量数据，不读取通信内容。暂停、隐藏页面、锁屏或休眠时停止观察，停止或关闭功能后停止新增采集并关闭过滤配置，已有历史按保留期清理，也可使用“清空记录”立即删除。地图从 `c.ysicing.net` 下载公共 IP 国家数据库及固定版本的 ip2region 省市和运营商数据库，缓存到本机离线查询，不向服务商发送连接目标 IP。大陆地址按城市聚合，缺失时回退省份或国家；坐标为地区代表点，不是设备精确位置。省市和运营商随本地连接历史清理。
- **应用活动**（实验性功能）：默认关闭。在“设置 → 功能 → 实验性功能”开启后，记录前台应用标识、名称、分类、使用时段，以及本机主机名和 Mac 型号，并使用存放在本机钥匙串中的设备密钥以 AES-GCM 加密写入本机 SQLite 数据库（无活跃操作超过 5 分钟暂停计时）。关闭记录会保留已有历史。
- **应用分身**（实验性功能）：默认关闭。在本机为所选应用创建独立资料目录与可选代理配置；更新或删除前仅在本机检查资料占用，不向外上传分身资料。
- **菜单栏折叠**（macOS 27 实验性功能）：默认关闭。开启应用图标折叠时，需要你授权访问单个系统配置文件（以安全书签形式保存授权），用于隐藏和恢复所选应用图标。

## 2. 更新检查与安装统计

检查更新时，应用向 XStats 更新服务发送版本号和安装标识的 SHA-256 哈希。安装标识在本机由随机值或机器序列号生成。更新服务入口为 `apps.china.12306.work`、`apps.12306.work` 和 `apps-api.xiai.me`。

服务保存哈希、版本、首次及最近检查时间和累计次数，用于安装量、版本分布与活跃情况统计；这些汇总记录长期保存，可申请删除。请求 IP 在内存中用于一分钟限流，网络基础设施可能按自身规则处理连接元数据。

可在“设置 → 关于”选择检查频率，或选择“从不”后仅手动检查。新版本由你决定是否下载安装。查询或删除统计记录时，可通过邮箱联系我们，并提供安装标识哈希以便定位。

## 3. 联网功能

- **公网 IP 与归属地**：公网 IP 查询使用 Cloudflare `1.1.1.1`，失败时回退到 ipify；归属地、ASN、网络类型与纯净度查询向 `cleanip.io` 发送公网 IP，结果缓存在本机。
- **WebRTC 检测**：向 `ipwho.is` 发送检出的 HTTP 和 STUN 公网 IP，查询地区、城市、机构、ISP 与服务商域名。结果在本机缓存 7 天，最多 256 个 IP；过期后按需刷新，失败时保留旧结果。关闭窗口或系统暂停时取消查询。
- **网络诊断**：连接探测、测速、出口检测与 DNS 查询会连接所选目标、测试节点、网站或 DNS 服务；对方可获取连接元数据及测试所需内容。
- **全球探针**：向 Globalping 提交输入的目标域名；测量参数和结果可通过测量 ID 被他人查询，请仅提交适合公开的目标。
- **跨设备加密同步**：默认关闭。在每台 Mac 的“设置 → 功能 → 可选功能”开启“同步”后，可通过 iCloud Drive、WebDAV 或 Google Drive 桌面版同步文件夹交换加密的应用活动分片、设备元数据（设备 UUID、名称及同步状态）以及你单独选择加入的功能设置（外观、菜单栏布局、内置休息提示音与休息提醒开关）。共享恢复密钥存放在钥匙串中，签名版可通过 iCloud 钥匙串在同 Apple Account 的受信任 Mac 间共享，也支持通过恢复码导入。存储服务商仍可看到同步文件的大小和修改时间；WebDAV 使用 HTTP 时仅限私有局域网或 Tailscale，且登录凭据会随 HTTP 发送（在数据集加密之外）；macOS 15 及以上访问局域网 WebDAV 可能需要系统“本地网络”权限。
- **监控大屏与只读 MCP**（实验性功能）：默认关闭。开启后会在同一局域网内免登录提供只读监控网页和 `/mcp` 接口；如另行开启“允许通过 Tailscale 访问”，则会向 Tailscale 网络开放上述只读接口。

第三方服务按各自的隐私政策处理请求信息。

## 4. 数据管理与联系

本机数据由你和 macOS 管理。卸载后，偏好、日志和已导出的诊断包可能保留，可自行删除。关闭相应功能可停止后续查询。

如需了解、更正或删除可定位的服务端记录，或有隐私问题，请联系 i@xiai.me。邮件用于处理你的请求，并按该用途及适用义务所需的期限保存。

处理方式发生重大变化时，我们会更新本政策及生效日期，并在应用或项目页面提供新版本。
