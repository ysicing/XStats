Mac 的状态，抬眼就看见

CPU、GPU、内存、网络与温度常驻菜单栏，还能调风扇、防休眠、一键清理、卸载应用，检测 IP 纯净度。所有数据在本机读取，没有统计上报。

每个指标一个图标，点开就是详情

原生 Swift 编写，只显示菜单栏时约 0.3% CPU、16 MB 内存。

  • 八种菜单栏风格

    双行文字、圆环、饼图、柱状历史……整体选一种统一套用，也能给单个指标单独指定。

  • 单项详情，按需显示

    CPU、内存、网络、GPU、磁盘、电池、温度各有一个窄弹窗，显示哪些区块由你勾选；另有侧边栏主窗口看全部。

  • 网络详情与 DNS

    本地与公网 IPv4 / IPv6、归属地与 ASN、连接探测格子，一键刷新 DNS 或切换 Cloudflare、Google、腾讯、阿里云。

  • IP 纯净度检测

    CleanIP.io 纯净度评分与 F 到 A+ 等级，一眼看出出口 IP 是否被标记为 VPN、代理、Tor、机房或有滥用记录；IPv4 / IPv6 分别检测。

  • 风扇调速与防休眠

    自动、降温、强冷、自定义风扇；屏幕常亮、合上屏幕继续运行，过热或电量过低时自动恢复。

  • 安全的清理

    缓存、日志、浏览器与开发者缓存先扫描预览再清理，钥匙串、Cookie 与历史记录一律不碰。

  • 卸载应用与启动项

    卸载时找出应用留下的缓存、偏好设置、容器与登录项，连同应用移到废纸篓可放回；LaunchAgents 与 LaunchDaemons 一览，自己的启动项一键停用。

  • 磁盘与电池

    空间占用分析、文件系统只读检查、本地快照与外置磁盘；电池 24 小时电量曲线、功耗、健康度与蓝牙设备电量。

  • 数据留在本机

    指标来自本机内核、IOKit 与 SMC，没有统计上报；账号可选，只用来同步设置；公网 IP 查询与连接探测都可关闭。

网络，一眼看到底

  • 上下镜像的流量历史，上传绿、下载蓝
  • 连接探测格子：每秒 ping 一次，通了是绿格、不通是红格，最近 60 次一眼看清
  • 本地与公网 IPv4 / IPv6、路由器、Wi‑Fi 信号，点一下就拷贝
  • 归属地显示国旗、城市、ASN 与网络运营方，原生 / 广播、住宅 / 机房直接标出
  • IP 纯净度：CleanIP.io 评分与 F 到 A+ 等级色带，列出 VPN、代理、Tor、机房、滥用记录等风险标记
  • 一键刷新 DNS 缓存，一键切换 Cloudflare、Google、腾讯 DNSPod、阿里云，或手动填写
  • 各进程的上传与下载速率

公网 IP 查询与连接探测都可以在设置里关闭。修改 DNS 需要管理员权限。

  • 统计上报没有

新增 5 · 样式 1

  • 新增新增出口与分流窗口：网络页顶栏和菜单栏网络弹窗各有一个入口。一次检测约十秒，看清 VPN 与代理有没有生效、各个网站分别从哪个出口出去。
  • 新增结论只用一句话说清：未使用代理、代理出口（地区）、代理没有生效、网络不通四种情况。右侧同时给出经代理、直连、连不上的网站数量。
  • 新增本机网络：物理网卡的出口 IP、归属地、运营商与 IPv6。归属地数据来自 cleanip.io。
  • 新增网站分流：25 个常用网站分别从哪个出口出去。按 AI、影音、社交、开发、国内分类筛选；接入 Cloudflare 的网站能实测出口与边缘节点，其余按国内 / 国际规则推断，每个网站带延迟信号条。
  • 新增代理方式一览：VPN / 隧道、系统代理、自动代理配置、DNS 与检测到的代理软件。DNS 被代理接管时会标出来。
  • 样式菜单栏网络弹窗的 DNS 区块重排：网络服务与线路做成两个徽章（Wi-Fi / 有线、直连或经过哪个代理），走隧道时标题旁有叹号提示 DNS 可能被接管，刷新 DNS 缓存改为图标按钮。
2026-09-180.5.0

新增 6

  • 新增新增网络测速窗口：网络页顶栏多一个“网络测速”按钮。窗口里四块内容各自独立，可以单独跑、也可以随时停，关窗即停。
  • 新增本机宽带测速：下行、上行、空载延迟与抖动。数据由 speed.cloudflare.com 测量，并显示这次走的是哪个 Cloudflare 边缘节点。
  • 新增国内分省三网延迟：31 个省份 × 三网共 93 个节点。给出电信、联通、移动各自的中位延迟与逐省数值；节点来自 zstaticcdn.com，只做 TCP 建连计时、不下载任何数据。
  • 新增全球节点测速：24 个节点，先测延迟再单独测下载。覆盖亚太、欧洲、北美等地，测速文件来自 Linode、Vultr、DataPacket。
  • 新增全球探针看目标：从全球 10 / 20 / 30 个社区探针 ping 你填的域名。看各地访问它的延迟与丢包，走 Globalping 的公开接口，请求从本机直接发出、不带任何密钥，用的是本机 IP 每小时的免费额度；测量结果在 Globalping 上公开，所以只测你自己填写的域名。
  • 新增测速有明确的用量上限：默认 10 秒 / 200 MB，先到哪个停哪个。顶栏可改成 3 秒 / 20 MB 或 5 秒 / 50 MB，并实时显示本次用掉多少流量。

2026-09-160.4.0

修复 1 · 调整 2 · 样式 6 · 新增 1

  • 修复修复网络弹窗偶尔露出一小截滚动条：以前弹窗打开时按当时的内容算高度，之后公网 IP、归属地等数据陆续到达，内容变高了窗口却不跟着变。现在内容一变高或变矮，窗口高度随之调整到正好放下，只有屏幕放不下时才出现滚动条；展开、收起区块时同样适用。
  • 调整网络弹窗只显示公网 IP，没有 IPv6 时不占行：本地 IPv4、本地 IPv6 与路由器只在主窗口的网络页显示；没有 IPv6 时不再显示“—”占一行，网卡没有 IPv6 地址就不显示“本地 IPv6”，拿不到公网 IPv6（网络或代理不支持）就不显示“公网 IPv6”。
  • 调整应用的 CPU 占用改为占整机的比例：CPU 弹窗与主窗口 CPU 页的“按应用汇总”、仪表盘的“高占用进程”，全部核心跑满为 100%，和顶部的总占用是同一把尺子。以前按单核满载为 100% 计（活动监视器的算法），多核 Mac 上一个应用动不动显示 99%、75%，容易误以为很吃 CPU；鼠标悬停在数值上仍可看到单核口径的数值。进程页保持单核口径，与活动监视器一致。
  • 样式主窗口在 macOS 26 上改用液态玻璃：侧边栏是一块浮在窗口里的玻璃面板，选中项垫一块淡蓝色圆角底并随切换滑动；顶栏右侧“在菜单栏显示”一组收进玻璃胶囊。主按钮是蓝色玻璃胶囊、次要按钮与图标按钮是透明玻璃，风扇模式等快捷切换是玻璃胶囊，开关换成系统开关（拖动时滑块变成玻璃）。设置分组与数据卡片保持实色，与系统设置一致。macOS 14、15 上保持原来的样式。
  • 样式菜单栏弹窗改为紧凑排版，参照 Stats：区块不再是灰底卡片，改成一条细分隔线隔开，行距收紧，顶栏按钮缩小；网络弹窗的 IP 纯净度与 DNS 默认收起成一行（纯净度显示分数与等级，DNS 显示正在使用的地址），点一下展开、标题栏右侧的箭头收起，状态会记住；流量图变矮，连接探测改为两行细格。网络弹窗从约 1520pt 降到约 950pt，其他弹窗矮了一到两成。主窗口的详情页保持原样，照常完整显示。
  • 样式IP 纯净度的标题行重新排版：置信度不再是带框的绿色徽章，改成标题旁一行浅灰小字，百分比按高低着色；“查看完整报告”文字链接换成外链图标，与刷新、收起并成一组按钮，macOS 26 上合成一颗玻璃胶囊。分数右侧的 cleanip.io 字标照旧可以打开完整报告。
  • 样式连接探测只用来看网络通不通：格子通了是绿色、不通是红色（不再用橙色表示延迟偏高），固定 60 格，弹窗排成 3 行、主窗口排成 2 行；去掉格子下面的延迟、抖动、丢包三项，标题右侧也不再写探测地址与频率。打开网络详情时固定每秒探测一次，「设置 · 网络」里的“探测间隔”选项随之去掉，后台低频探测仍是每 10 秒。
  • 样式主窗口顶栏加高，右上角按钮高度统一：顶栏改为标准高度（52pt，原来 40pt），右上角的按钮、“在菜单栏显示”开关组与“防休眠已开启”标记统一为 32pt 高，上下各留 10pt，各页高度一致，不再偏上。macOS 26 上红绿灯按钮留在侧边栏玻璃面板之外，面板从顶栏下方开始、与右侧内容卡片顶边对齐，顶栏那一条可以按住拖动窗口。

常见问题

会不会很耗电？

只显示菜单栏时只采集菜单栏用到的指标，M5 Max 实测约 0.3% CPU、16 MB 内存；锁屏、屏幕休眠和系统睡眠时暂停采样与探测。

辅助工具是做什么的，安全吗？

调风扇、合盖不睡眠、刷新 DNS、修改 DNS 服务器和释放内存需要系统权限，由一个通过 SMAppService 注册的辅助工具完成。它只提供这几个固定操作，不执行任意命令，DNS 地址会再次校验；只接受同一开发团队签名的 OpenStats 调用，应用退出时自动恢复风扇与睡眠设置。

会联网吗？

只有几项可关闭的功能会：打开网络详情时向 Cloudflare 查询一次公网地址（10 分钟内不重复）；连接探测按你设定的间隔 ping 你选择的目标；归属地、ASN 与纯净度评分由这台 Mac 直接向 cleanip.io 查询，只发送公网地址；每天从本站检查一次新版本。账号可选，只用来同步设置；没有统计上报。

为什么不上 App Store？

App Store 的沙盒不允许访问 SMC、读取其他应用的缓存和安装特权辅助工具，而这正是大部分功能。

清理会不会删掉重要文件？

只清理白名单目录中的缓存与日志，钥匙串、密码管理器、VPN、Cookie、历史记录一律不碰；清理前可以展开查看每一项，下载目录中的内容会先移到废纸篓。

怎么安装、卸载？

下载 DMG 后把 OpenStats 拖进“应用程序”；也可以用 Homebrew：brew install --cask gentpan/tap/openstats。卸载时先在“设置 › 辅助工具”里卸载辅助工具，再把应用移到废纸篓；用 Homebrew 安装的执行 brew uninstall --zap --cask openstats。

菜单栏图标的顺序怎么调？

按住 ⌘ 键拖动任意一个图标即可，松开后位置会一直保留，重启也不变。新开启的项目由 macOS 安排初始位置，可能离其他图标较远，拖到一起就好。这是系统自带的功能，对所有菜单栏图标都有效。

支持 Intel Mac 吗？

支持，在上方下载 Intel 版即可，需要 macOS 14 Sonoma 或更高版本。用 Apple 智能解释进程只能在 Apple 芯片上使用；Intel 机型的 CPU 不分性能核与能效核，部分功耗与频率读数也可能不显示。开发主要在 Apple 芯片上进行，Intel 机型遇到风扇或温度读数不对，欢迎到 GitHub 反馈。
